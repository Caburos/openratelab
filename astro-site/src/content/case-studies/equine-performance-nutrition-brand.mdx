## The Objective

This equine performance nutrition brand had one clear hero product and
nothing else. No consistent way to keep bringing new attention back to it
without repeating the same angle every time.

Repeating the same email again and again burns out a list fast. We needed
a way to say the same thing without saying it the same way twice.

**Program length:** 12+ MO &nbsp;&nbsp; **Revenue per send:** $650–$830

## What We Did

We built four separate angles on the same product and let the data tell
us if the underlying pattern held.

We built a rotating set of educational, no-incentive emails about the
hero product. Each one approached it from a different angle: performance,
recovery, routine, trust. No single evergreen template carrying the whole
program.

Four distinct creative angles have each independently produced this
range, replicated over 12+ months (a validated, repeatable pattern):
**$650–$830** revenue per educational send.

## The Delta

Quantitative outcomes from the account's Klaviyo campaign reporting. Each
of the four angles landed in the same $650 to $830 range on its own.
Twelve months in, the pattern still holds every time we run it.

- **Revenue per send:** $650–$830 (per angle)
- **Angles replicated:** 4X (independent)
- **Program length:** 12+ MO (ongoing)
