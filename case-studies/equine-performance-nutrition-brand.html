01. ANALYSIS

This equine performance nutrition brand had one clear hero product and nothing else. No consistent way to keep bringing new attention back to it without repeating the same angle every time.

Repeating the same email again and again burns out a list fast. We needed a way to say the same thing without saying it the same way twice.

PROGRAM LENGTH

12+ MO

[ INFRASTRUCTURE ]

WHAT WE DID

We built four separate angles on the same product and let the data tell us if the underlying pattern actually held.

01 / APPROACH

ROTATING
EDUCATIONAL ANGLES

We built a rotating set of educational, no-incentive emails about the hero product. Each one approached it from a different angle: performance, recovery, routine, trust. No single evergreen template carrying the whole program.
